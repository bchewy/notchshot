# NotchShot 0.8.1

## New

- **An app icon.** NotchShot now has its own icon in Finder, Spotlight, and System Settings: its mint aperture on a dark tile, with the MacBook notch hanging from the top edge. It follows Apple's app icon shape, so macOS 26 shows it like its own apps instead of on a gray plate. Earlier releases showed the generic app icon.

## Upgrading

0.7.0 and later install this update automatically on the Stable channel, or right away with **Check for updates…** in the menu bar. Coming from 0.6.0 or earlier, install it by hand once; see the [0.7.0 notes](0.7.0.md#upgrading-from-060).

## Release status

Requires Apple silicon and macOS 15 or newer. This release is not notarized by Apple. Accessibility and Screen Recording permissions are required for full capture.

All 454 automated tests pass with no skips. The icon is drawn by `script/make_app_icon.swift`, and every build, including this release, bundles it. The only app change since 0.8.0 is the icon; see the [0.8.0 notes](0.8.0.md) for the rest of this cycle.
