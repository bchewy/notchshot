# NotchShot 0.8.2

## New

- **Drag-to-Applications install.** Each release now includes `NotchShot-0.8.2.dmg`. Open it and drag NotchShot onto the Applications shortcut. Installing into Applications also lets NotchShot update itself: copies running from Downloads or from the disk image can't replace themselves.
- The ZIP is still published, and it's what automatic updates install.

## Upgrading

0.7.0 and later install this update automatically on the Stable channel, or right away with **Check for updates…** in the menu bar. There are no app changes since 0.8.1.

## Release status

Requires Apple silicon and macOS 15 or newer. This release is not notarized by Apple: the first time you open it, macOS may block it. Choose **Open Anyway** in System Settings → Privacy & Security. Accessibility and Screen Recording permissions are required for full capture.

All 455 automated tests pass with no skips, including one confirming that automatic updates keep installing the ZIP when a release also has a disk image. Before publishing, the packager mounts the disk image read-only. It checks that the image shows only NotchShot and the Applications link, and that the app inside is byte-identical to the signed build and passes strict signature checks.
