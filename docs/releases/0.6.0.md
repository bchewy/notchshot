# NotchShot 0.6.0 preview

## New

- Choose **Screenshot + AX tree**, **Image only**, or **AX tree only** for copying. The choice applies to individual shots, hover copy, selections, and automatic copy.
- Pick Mint, Sky, Lavender, Rose, Peach, or Gold in **Settings → Appearance**.
- Clear the entire shelf with the small trash button in the compact notch. Previously copied content and exported files remain available.
- Enable **Settings → Display → Follow active screen** to follow your pointer between displays. Following waits while you interact, capture, or drag, and preserves the current shelf and page. Off by default.
- Use the integrated Settings scrollbar with a larger interactive area.

## Fixes

- Copied context preserves the accessibility tree instead of duplicating flat text and OCR. Missing or shortened tree content is explicitly marked.
- Capture-card landing follows the notch's current display. Display changes preserve native panel state and refresh animation bounds.
- Settings shows the build's source revision; release archives are paired with their exact corresponding source.

## Preview status

Not yet published. The website retains its 0.5.2 download until signing,
packaging, and final installed-build verification are complete.

Requires Apple silicon and macOS 15 or newer. This preview is not notarized by Apple. Accessibility and Screen Recording permissions are required for full capture.

All 362 automated tests pass in debug and optimized release builds. Live settings checks passed; final physical capture/paste, clear-all, multi-monitor movement, and scrollbar keyboard-focus checks remain pending. Destination apps decide which clipboard formats and attachment counts they accept. Image-only multi-shot copy requires rich-document support; combined mode offers optional image-then-text assistance.
