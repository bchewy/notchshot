# NotchShot 0.6.0 preview

## New

- Choose **Screenshot + AX tree**, **Image only**, or **AX tree only** for copying. The choice applies to individual shots, hover copy, selections, and automatic copy.
- Pick Mint, Sky, Lavender, Rose, Peach, or Gold in **Settings → Appearance**.
- Clear the entire shelf with the small trash button in the compact notch. Previously copied content and exported files remain available.
- Enable **Settings → Display → Follow active screen** to follow your pointer between displays. Following waits while you interact, capture, or drag, and preserves the current shelf and page. Off by default.
- Use the integrated Settings scrollbar with a larger interactive area.

## Fixes

- Copied context preserves the accessibility tree instead of duplicating flat text and OCR. Missing or shortened tree content is explicitly marked.
- Capture-card landing follows the notch's current display. Display changes preserve native panel state and refresh animation bounds.
- Settings shows the build's source revision; release archives are paired with their exact corresponding source.
- Canceling a capture stops its accessibility/OCR workers and prevents later stages from publishing stale results.
- Paste assistance reports clipboard-restoration failures and preserves queued cleanup across repeated cancellation.
- Copy-collapse deadlines reject stale callbacks; timing tests no longer rely on a lightly loaded machine.
- Native page-motion tests cover both animation and Reduce Motion independently of the runner’s accessibility settings, without skipping CI coverage.

## Preview status

Download the app and matching source from [notchshot.com](https://notchshot.com)
or the [0.6.0 GitHub preview release](https://github.com/bchewy/notchshot/releases/tag/v0.6.0).
Build 29 corresponds to source commit `5fd8876c4e9dbc1eaba4b4dd215965db6b5f6f77`;
checksums and a release manifest accompany both archives.

Requires Apple silicon and macOS 15 or newer. This preview is not notarized by Apple. Accessibility and Screen Recording permissions are required for full capture.

All 378 automated tests pass locally in debug and optimized release builds, with no skips. GitHub CI requires the full suite to execute, including native-motion coverage. The signed preview passed live settings and scrollbar Home/End checks. Physical capture and two-shot rich copying/pasting into TextEdit delivered both images and the complete copied context. Physical clear-all, multi-monitor movement, and assisted pasting into web composers were not repeated in this pass. Destination apps decide which clipboard formats and attachment counts they accept. Image-only multi-shot copy requires rich-document support; combined mode offers optional image-then-text assistance.
