# NotchShot 0.8.3

## Getting ready for notarized releases

This release prepares NotchShot's updater for releases signed with the developer's Developer ID certificate and notarized by Apple. Notarized releases open without macOS asking you to choose Open Anyway.

- Updates still accept only NotchShot builds from its own developer. Besides this copy's own signature, the updater now accepts one other exact identity: NotchShot signed with the team's Developer ID certificate. Nothing else is accepted.
- There are no other changes.

## When the first notarized release arrives

It installs automatically like any update. Because it's signed with a different certificate, macOS asks once more for **Accessibility** and **Screen Recording**. Grant them in System Settings → Privacy & Security, and NotchShot works as before.

## Release status

Requires Apple silicon and macOS 15 or newer. This release itself is not notarized. All 456 automated tests pass with no skips, including one that checks the updater accepts the Developer ID identity only as a fallback and still rejects apps from any other signer.
