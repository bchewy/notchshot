# NotchShot 0.7.0

## New

- **Automatic updates.** NotchShot now keeps itself current from GitHub Releases. Choose **Stable** (tagged releases) or **Nightly** (daily builds of `main`, which also take newer stable releases) in **Settings → Updates**, or use **Check for updates…** in the menu bar.
- Updates download in the background and install only when nothing would be lost: the shelf is empty and the notch is closed. NotchShot then reopens in about a second. Otherwise the update waits and installs when you quit. **Restart to update** installs it right away.
- Every update is verified before it can run. The archive must match its published checksum, and the app must carry the same code signature as the copy you are running, with certificate revocation checked. Accessibility and Screen Recording permissions carry over. Updates never install an older build.
- Turning off **Install updates automatically** stops all background network access; NotchShot then checks only when you ask. Checks are anonymous HTTPS requests to GitHub, and captures never leave your Mac.

## Upgrading from 0.6.0

0.6.0 has no updater, so install 0.7.0 by hand once: quit NotchShot, replace the app with the one from this release, and reopen it. It is signed with the same certificate, so your permissions carry over. Later releases arrive automatically.

## Release status

Requires Apple silicon and macOS 15 or newer. This release is not notarized by Apple. Accessibility and Screen Recording permissions are required for full capture. Build numbers now count commits on `main`, so this build is numbered above 0.6.0's build 29.

All 412 automated tests pass with no skips, including checksum, archive, Info.plist, and code-signature rejection cases. Before release, the updater ran end to end on a Mac: a Stable-channel test build discovered the published 0.6.0 release on GitHub, verified its checksum and signature with revocation checking, swapped it into place, and relaunched into it about 20 seconds after launch. A copy with one modified resource was rejected. This is the first release built, signed, and published by GitHub Actions.

See the [user guide](https://github.com/bchewy/notchshot/blob/main/docs/USER_GUIDE.md#updates) and [release process](https://github.com/bchewy/notchshot/blob/main/docs/RELEASING.md).
